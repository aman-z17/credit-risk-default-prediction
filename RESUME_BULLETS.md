# Resume bullets

## Recommended version

**Credit Risk Default Prediction Model — Machine Learning Research**

- Engineered a reproducible synthetic dataset of 10,000 loan applicants with
  eight financial features using Python, NumPy, and Pandas; built leakage-safe
  logistic-regression and random-forest classification workflows.
- Achieved 85.2% held-out accuracy and 0.854 ROC-AUC with logistic regression;
  used permutation importance to identify late payments, credit utilization,
  and credit-history length as the strongest default predictors.
- Evaluated business-aware classification thresholds with out-of-fold
  predictions, increasing default recall from 43.1% to 79.3% under an
  illustrative asymmetric-cost assumption.

## Compact two-bullet version

- Engineered a reproducible synthetic 10,000-applicant, eight-feature credit
  dataset with Python, NumPy, and Pandas; trained and compared logistic
  regression and tuned random-forest default classifiers.
- Achieved 85.2% accuracy and 0.854 ROC-AUC on a held-out test set; identified
  late payments, credit utilization, and credit-history length as the leading
  predictors and improved default recall to 79.3% through training-selected
  threshold analysis.
